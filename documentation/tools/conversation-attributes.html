Conversation & attribute tools

Help, handover, clarify, retry, advice; attribute and category metadata for filtering and discovery.

conversation.help

  • Returns a fixed help message: what the bot can do (find products, track orders, cart) and example phrases. No params.

conversation.handover

  • Flags the conversation for a human agent; optional reason. Returns a message that someone will review shortly; action: "handover_initiated".

conversation.end

  • Ends the session with a goodbye message; action: "session_ended".

conversation.feedback

  • Collects rating (1–5) and optional comment; logs and returns a thank-you message.

conversation.retry

  • Used when the user says “Try again”, “Retry”, “Repeat”. Returns is_retry: true so the orchestrator can re-run the last tool.

conversation.clarify

  • When intent is ambiguous (e.g. INTENT ADVISOR suggests clarification). Params: reason, options (possible interpretations). Returns a “Could you clarify?” message and action: "clarification_requested".

What it does

  • Uses the AI to give short, actionable shopping advice. Injects store context (categories, vendors) and user category, need, query into a prompt; returns advice and suggested_action (e.g. “Would you like me to search for [category]?”).
  • Use only when the user clearly asks for advice or help choosing; avoid over-triggering on generic search.

attribute.list

  • Lists filter attributes for a category_slug from store context (category’s attributes array → ATTRIBUTES). Returns label, code, value_count.

attribute.getValues

  • Returns valid values for an attribute_code (or label); optional category_slug. Uses ATTRIBUTES and predefined_values.

attribute.findByCategory

  • Same idea as list but returns full attribute objects (code, label, type, values) for the category.

category.list

  • Use only when the user wants to see all categories (e.g. “what categories do you have?”). Returns root categories with label and count. Do not use when the user names a specific category.

category.getInfo

  • Returns details for a named category: id, label, slug, description, product_count, has_children. Params: category (name or slug).

category.getSubcategories

  • Returns child categories of a parent (e.g. “what kinds of headphones?”). Params: category (parent name or slug).

category.getAttributes

  • Returns available filter attributes for a category (label, code, type) from store context.
