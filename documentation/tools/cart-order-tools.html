Cart & order tools

View cart, add/remove/update items; list orders, track status, checkout (including WhatsApp-style checkout).

What it does

  • Fetches cart for sessionId via /cart?session_id=...; returns items, total, item_count.
  • Syncs cart summary to state via stateManager.updateCart.
  • Returns vendor_groups (vendorId, businessName, checkoutStyle, item_count, subtotal) for multi-vendor checkout.
  • Empty cart returns a friendly “Your cart is empty” message.

What it does

  • Resolves product_id via resolveProduct(identifier, context) — supports product name, “the first one”, “it”, etc.
  • If resolution fails, returns a clear error suggesting the user name the product or use “the first one” after a search.
  • Fetches product from backend, POSTs to /cart/items with product_id, quantity, price, session_id.
  • Updates state cart summary and optionally tracks abandoned_items for the added product.

Key params

  • product_id — product ID, name, or reference (“the first one”, “the cheap one”, “it”).
  • quantity — default 1.

Engineered tokens (post-add buttons)

  • __cart:view__, __order:checkout__, __shop:continue__ — common follow-up actions.

cart.remove

  • Removes by cart_item_id or by product_id (resolved to cart item via cart contents or resolveProduct).
  • Supports “remove the first two” via pipeline expansion to multiple cart_item_ids.
  • DELETE /cart/items/:cart_item_id; updates state cart summary.

cart.updateQuantity

  • Updates quantity for a cart item; locates item by cart_item_id or product_id (resolved/fuzzy match).
  • PATCH /cart/items/:cart_item_id with { quantity }; quantity must be ≥ 1.

order.list

  • Lists recent orders for the session via /orders?session_id=...; returns order_number, status, total, created_at, item_count.

order.track

  • Fetches a single order by order_number; returns status, total, items, tracking_url.

What it does

  • Loads cart; if empty, returns error. Groups items by vendor (vendorGroups).
  • Per vendor: if checkoutStyle === 'whatsapp', POSTs to /orders/whatsapp with vendorId, items, total, customerName, customerEmail.
  • Returns checkout links or instructions (e.g. WhatsApp contact links) so the user can complete payment/messaging per vendor.
  • Optional params: customer_name, customer_email for order records.

Engineered tokens

  • __order:checkout__ — often used as a button to start checkout from cart view.
