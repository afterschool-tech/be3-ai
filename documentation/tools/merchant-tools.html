Vendor & collection tools

Vendor listing, products by vendor, identity checks, contact links; collection listing and products by collection.

What it does

  • Returns all available vendors from context.VENDORS with name, tag, product_count, delivery_scope.
  • No params; used when the user asks “who are the sellers?” or “list vendors”.

What it does

  • Resolves vendor by name, tag, or “their” from conversation history.
  • Calls backend search with attribute.vendor (vendor tag), optional category, limit, page, sort, attributes.
  • Stores a search snapshot for __nav:more:<snapshotId>__ paging; updates reference_map for pronoun resolution.
  • Returns product cards and facet/refiner buttons like product.search.

Key params

  • vendor / vendor_name — vendor name, tag, or “their”.
  • category, limit, page, sort, attributes.

Engineered tokens

  • __nav:more:<snapshotId>__ — next page of vendor products.

What it does

  • Verifies whether a product belongs to a vendor (e.g. “Is this iPhone from Apple?”).
  • Resolves vendor from context; fetches product and checks created_by or tags against vendor.
  • Returns belongs_to_vendor, creator_match, tag_match.

What it does

  • Returns vendor details (from context) and WhatsApp buttons: “See products”, “Contact [vendor]”.
  • Used when the user asks about a vendor or from product.getDetails via __vendor:info:<vendorKey>__.

Engineered tokens

  • __vendor:products:<vendorKey>__ — list vendor products.
  • __vendor:contact:<vendorKey>__ — opens vendor.getContactLink.

What it does

  • Builds a wa.me/<phone> link for the vendor; optional message pre-fills the chat.
  • Requires vendor.whatsapp_phone in context; returns whatsapp_link, phone, message_preview.
  • Use when the user says “send them a message”, “tell them …”, or “contact [vendor]” with specific text.

collection.list

  • Lists collections from COLLECTIONS context or backend /collections; returns id, title, slug, description, product_count.

collection.getProducts

  • Fetches products for a collection by collection_slug (e.g. new-arrivals); uses /collections/:slug/products, fallback by ID if slug fails.
  • Params: collection_slug, limit (default 10).
