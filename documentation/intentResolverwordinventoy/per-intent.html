Per-intent inventories (keywords & synonyms)

This page is the enumerated intent-by-intent lexicon list. Use search to filter intent cards.

Every intent file in src/services/intentResolver/config/intents/ defines:

  • keywords — primary triggers (“core verbs/signals”).
  • synonyms — recall expansion phrases (single- or multi-word).

What keywords do

  • Used in candidate detection.
  • Used in schema keyword scoring.
  • Used for IDF map building.
  • Used as fuzzy correction targets (fuzzyMatcher corrects toward keywords).
  • IntentScorer treats matched keywords as 5x weight vs synonyms.

What keywords do NOT do

  • They don’t extract parameters.
  • They don’t guarantee the intent wins; schema fit and action verbs can override.

Questions before adding a keyword

  • Is it a single, unambiguous action word for this intent?
  • Would you want fuzzyMatcher to correct typos into this word?
  • Will adding it to multiple intents reduce its IDF usefulness?

What synonyms do

  • CandidateDetector uses them to match phrases and extra words.
  • Multi-word synonyms are especially strong signals in candidate detection.

Questions before adding a synonym

  • Is it a phrase users actually say?
  • Is it too generic and shared across many intents?
  • If generic, should it be in weakSynonyms instead (so it’s weak)?
