Inline inventories (pipeline guards)

Inline lists outside config/* that materially change routing, residual formation, and scoring.

What it does

  • Maps specific verbs to action categories.
  • Produces action entities.
  • Feeds schema routing (high-precision intent bias).

What it does NOT do

  • Does not capture multi-word action phrases (single tokens only).
  • Does not add “semantic synonyms” unless you explicitly add them.

Questions before adding a verb

  • Is the verb ambiguous in shopping context? (If yes, it will misroute.)
  • Does it map cleanly to exactly one action category?
  • Do you need it as an action signal, or is it better as an intent synonym?

If not here, add it instead

  • Multi-word phrase (“take my money”): add to intent synonyms.
  • Generic desire (“I want”): add to weakSynonyms.

What it does NOT do

Questions before adding
