Global inventories (config)

Lists in src/services/intentResolver/config/ that affect fuzzy matching, candidate detection, splitting, and inversion.

What it does

  • Used to skip certain words when pipeline/fuzzyMatcher.js decides what words to even attempt to correct.
  • Used by orphan fallback in pipeline/candidateDetector.js (“if any non-stop-words exist, default to product_search”).

What it does NOT do

  • Does not stop a word from matching intent keywords/synonyms directly.
  • Is not the main place to remove social chatter from residual product text.

Questions before adding

  • Will you regret never correcting typos for this word?
  • Is it purely grammatical, or does it carry commerce meaning?
  • If it’s commerce meaning (cart, track, checkout), should it really be skipped in fuzzy correction?

If not here, add it instead

  • Social noise (hi/thanks/please): prefer FILLERS or nlpCleaner.cleanQuery() greetings.
  • Generic phrase causing false intent matches: consider weakSynonyms.

This file doesn’t contain word lists, but it controls how your word lists are consumed.

What it does

  • Loads all intents.
  • Exposes getAllKeywords(), buildKeywordMap(), and buildIdfMap() for keyword + synonym tokens across intents.

What it does NOT do

  • Does not apply stopword/common word filtering when building IDF. All tokens count.

Questions before adding new intent words

  • Will this word show up in many intents and reduce its IDF signal?
  • Is it so common that it dilutes IDF without adding meaning?
