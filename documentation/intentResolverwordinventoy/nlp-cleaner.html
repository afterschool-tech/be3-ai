Cleaning inventories (nlpCleaner.js)

Lists that aggressively remove social noise and action scaffolding to produce product-like query strings.

What it does

  • Removes adverbs using compromise.
  • Lowercases and strips punctuation with a regex.

What it does NOT do

  • Does not remove conjunctions by default (line is commented out).
  • Does not remove pronouns/prepositions.

When to modify

  • Only if you see adverbs/punctuation harming intent detection.

List

  • hello, hi, hey, yo, sup

What it does

  • Removes greeting tokens.

What it does NOT do

  • Doesn’t remove please/thanks (that’s in cleanQuery).

actionNoise: get, show, find, view, search, give, want, need, buy

greetings/politeness: hello, hi, hey, yo, sup, please, thanks, thank you

What it does

  • Aggressively removes: adverbs, conjunctions, prepositions, pronouns, modals.
  • Removes common action verbs that pollute search/product mentions.
  • Removes greetings/politeness.
  • Produces a product-like query string.

What it does NOT do

  • Does not “understand products”; it only removes noise.
  • Can’t safely remove domain words without risk.

Questions before adding to actionNoise

  • Is this word never part of a product name in your catalog?
  • Will removing it cause loss of meaning in queries like “case for iphone”?

If not here, add it instead

  • Intent misclassification: tune intent keywords/synonyms or ACTION_VERBS.
  • Residual lumps: add to FILLERS.
